# ea6350-firmware-manager 1.0.1

Пакет для Linksys EA6350v3 на OpenWrt 25.12.x.

## Что изменено в 1.0.1

- исправлено переключение слотов: теперь команда действительно вызывает `reboot` после изменения `boot_part`;
- добавлена проверка реальной схемы MTD перед опасными операциями;
- factory image проверяется до записи: FIT header в начале и UBI header на смещении rootfs;
- после записи проверяются FIT и UBI в целевом слоте;
- сохранена защита OEM и запрет записи активного слота;
- сохранено намеренное отклонение `sysupgrade.bin`.

## Схема EA6350v3

На роутере используются перекрывающиеся MTD-области:

- slot 1: `kernel` + физически следующие данные `rootfs`;
- slot 2: `alt_kernel` + физически следующие данные `alt_rootfs`;
- U-Boot выбирает слот через `boot_part=1|2`.

OpenWrt factory image для EA6350v3 является составным образом: FIT kernel + UBI rootfs. Поэтому менеджер пишет его в MTD `kernel` или `alt_kernel`, которые охватывают физический 40-MiB слот. Активный слот никогда не выбирается целью.

## Что есть в LuCI

`Система → EA6350 Firmware Manager`

- показывает активный слот;
- показывает состояние обоих слотов: OpenWrt / OEM / Unknown;
- показывает `kernsize`;
- переключает загрузку на другой слот и сразу перезагружает роутер;
- записывает EA6350v3 `squashfs-factory.bin` в выбранный неактивный слот;
- защищает OEM от случайной перезаписи;
- проверяет образ до записи и результат после записи.

## Почему sysupgrade.bin отклоняется

`sysupgrade.bin` предназначен для штатного OpenWrt sysupgrade. Наша операция другая: записать конкретный полный EA6350v3 factory-образ в конкретный неактивный слот, не меняя `boot_part` автоматически. Поэтому менеджер принимает только `squashfs-factory.bin`.

## Безопасный сценарий сохранения OEM

Если один слот содержит OpenWrt, а второй OEM Linksys:

1. Advanced Reboot → загрузиться в OEM;
2. штатный интерфейс Linksys → Manual Update;
3. указать OpenWrt factory image;
4. штатная логика Linksys запишет новый OpenWrt в противоположный слот;
5. OEM останется в исходном слоте.

Если же в EA6350 Firmware Manager выбрать OEM-слот как цель, запись заблокирована до явной установки галочки «Я сознательно разрешаю удалить OEM Linksys».

## Сборка

Каталог:

`package/utils/ea6350-firmware-manager/`

Сборка:

`make package/ea6350-firmware-manager/compile V=s`

Для OpenWrt 25.12 используется APK.

Установка локального неподписанного пакета:

`apk --allow-untrusted add ea6350-firmware-manager_*.apk`
